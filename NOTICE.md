# Third-party model assets

`taxotag` does not include Desert Ant Labs model weights or taxonomy assets.
When downloaded at runtime, those assets come from the
`desert-ant-labs/gist` Hugging Face repository at revision `v2.2.0` and are
subject to the Desert Ant Labs Source-Available License.

That license is separate from the MIT license covering the `taxotag` wrapper
code. Review the model license before using the assets in a commercial
deployment.
